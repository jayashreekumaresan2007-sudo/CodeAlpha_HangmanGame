
# Hangman Game 

A simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

##  Project Description

Hangman is a word-guessing game where the player tries to identify a randomly selected hidden word by guessing one letter at a time.

The player gets a maximum of 6 incorrect attempts to guess the word correctly.

##  Features

- Random word selection from 5 predefined words.
- Maximum of 6 incorrect attempts.
- Input validation for letters.
- Duplicate guess detection.
- Displays correctly guessed letters.
- Win and Game Over conditions.
- Option to play multiple rounds.
- Simple command-line interface.

##  Game Rules

1. The computer randomly selects a word.
2. Guess one letter at a time.
3. Correct guesses reveal the letters.
4. Incorrect guesses reduce the remaining attempts.
5. You lose after 6 incorrect guesses.
6. Guess the complete word to win!
